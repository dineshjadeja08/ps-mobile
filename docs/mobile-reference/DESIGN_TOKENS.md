## Scale

- Spacing: `4, 8, 12, 16, 24, 32`.
- Screen horizontal padding: `16`.
- Card inner padding: `16–20`.
- Compact radius: `10–12`.
- Service/card radius: `20–24`.
- Sheet/modal radius: `28–32`.
- Pill radius: `999`.
- Minimum tap target: `44`.
- Header back circle: about `44 × 44`.
- Search: about `52–58` high.
- Primary button: `54` high.
- Bottom navigation: about `76` plus safe area; center action about `66` diameter.

## Type

Purple Squad uses Manrope. Approximate hierarchy:

- Auth hero/title: `30–34`, extra-bold.
- Screen header: `24–28`, extra-bold.
- Section header: `20–22`, bold/extra-bold.
- Card title: `17–20`, bold.
- Button: `15–17`, bold.
- Body: `13–15`, regular/medium, line-height `20–23`.
- Metadata: `10–12`, medium/semibold.

## Shadows

- Cards: low-opacity black shadow, 6–14 px blur, 3–6 px downward offset.
- Header utilities: small shadow plus a colored 2–3 px bottom accent.
- Sticky CTA container: white surface with upward soft shadow.

## Imagery

- Authentication: full-bleed vertical editorial photo with a dark text-safe zone.
- Home promo: full-width ~2:1 banner.
- Categories: portrait or square images, cropped consistently.
- Service listing: wide image approximately `1.5:1`, with a duration pill overlapping the lower-right corner.
- No Home Needs Pro photography is shipped. Purple Squad uses backend/owned assets and an original generated welcome image.
